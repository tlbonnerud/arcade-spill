# waves/

De 10 bølgene som **data**, ikke kode. Én rad per bølge i `waves.gd`:
fiendetyper og antall, pool av formasjoner, bevegelses- og innflygingsmønstre,
og skalering. Motoren som kjører dem er `core/wave_manager.gd`.

Format og begrunnelse: `docs/ARCHITECTURE.md`. Innholdet: `docs/DESIGN.md`.
Kommer i roadmap steg 2.
